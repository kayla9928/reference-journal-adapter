# Trigger Cases

Use these prompts to verify implicit routing and scope behavior. Evaluate the decision path, not exact wording.

## Should trigger

1. "I have the official author guide and template for a journal. Help me create a Zotero CSL, but ask before downloading anything else."
   - Offer the acquisition choice, identify missing evidence, and require specification freeze before implementation.
2. "Audit this custom CSL against our already frozen journal formatting matrix and prepare a Zotero witness."
   - Enter the existing-CSL audit route without reopening frozen source conflicts.
3. "The official CSL library has two close candidates. Adapt the safest parent and borrow a date macro from the other if justified."
   - Apply hard gates, one structural owner, and controlled dependency-closed borrowing.
4. "Check whether the official exact-match style is suitable for our confirmed Zotero requirements."
   - Verify before proposing a rewrite.
5. "You may retrieve the current official guide and template from the journal website; start by listing what you will use."
   - Do not redundantly ask whether browsing is allowed; state the bounded acquisition plan and proceed within it.
6. "I uploaded the `.ens`; please retrieve the official guide yourself and tell me if a published bibliography example is later needed."
   - Use a mixed local/official route and pause only for a new material gap or expanded access.

## Should not trigger

1. "Find the best hepatology journal for my review."
   - Journal selection belongs elsewhere.
2. "Clean the DOI, PMID, page, and journal abbreviation fields in my Zotero library."
   - Metadata governance is excluded.
3. "Convert these five references to Vancouver text."
   - Plain-text conversion is excluded.
4. "Move all citations after punctuation in my Word manuscript."
   - Manuscript placement/editing is excluded.
5. "Install this ready-made Zotero style."
   - Installation alone is excluded.

## Should stop at a boundary

1. Only two sample references are supplied and no authoritative specification can be formed.
   - Report the evidence gap; do not infer a complete journal style.
2. No candidate passes the frozen hard requirements.
   - Produce a gap report and defer from-scratch construction even if the user repeats the request to continue; route expansion to separate design.
3. Adapting requires replacing citation, bibliography, name, date, and sorting architectures from different styles.
   - Classify as unsupported broad composition and request an explicit scope decision.
