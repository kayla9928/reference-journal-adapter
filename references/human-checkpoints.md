# Human Checkpoints

Read this reference when the user can choose a source path, a material uncertainty appears, permissions would expand, or execution reaches a mandatory witness.

## Mandatory checkpoints

Pause for explicit user input at the initial acquisition choice when the user has not already chosen, material evidence conflicts, specification freeze, new dependency installation or expanded external access, final Zotero witness, and any later proposal to unfreeze a rule. If no suitable parent exists or broad composition is required, stop the v0.1 workflow after reporting the gap; do not treat a request to continue as an implementation approval for an undefined route.

Do not pause for local scans, already authorized official downloads, deterministic script runs, small edits within the frozen specification, or rerunning established tests.

## Ask decision-sized questions

State the decision required now, verified facts, unresolved point, recommended option first, realistic alternatives and consequences, the smallest evidence needed, and what can continue if the decision is deferred.

Do not ask the user to rediscover material already available in approved sources. Do not request whole libraries or manuscripts when a small witness will answer the question.

## Preserve authority

User confirmation freezes format choices but does not validate bibliographic facts. Record exactly what the user decided and its scope. A later output mismatch does not revoke that decision unless new evidence is explicitly admitted and the specification is unfrozen.
